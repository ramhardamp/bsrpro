🔒 APK इंस्टॉल और Verify🔒 Install & Verify the APK

इंस्टॉल से पहले file की जाँच करना सबसे सुरक्षित तरीका है।

Verifying the file before installing is the safest way.

1. Download

APK सिर्फ इसी पेज के GitHub Release बटन से डाउनलोड करें।

Download the APK only from the GitHub Release button on this page.

2. Verify

Release page पर दिया SHA-256 checksum अपनी file से मिलाएँ:

Compare the SHA-256 checksum on the Release page with your file:

sha256sum <apk file name>

3. Install

Settings → “Install unknown apps” में अपना browser/file manager allow करें, फिर APK खोलें। इंस्टॉल के बाद permission वापस बंद कर दें।

Allow your browser/file manager under Settings → “Install unknown apps”, open the APK, then turn the permission off again.

❓ अक्सर पूछे जाने वाले सवाल ❓ Frequently Asked Questions

क्या ये extensions मेरा data collect करते हैं?Do these extensions collect my data?
Privacy Shield और Password Manager आपकी browsing history या passwords developer को नहीं भेजते। ये कुछ network requests करते हैं: Shield filter lists download करता है (easylist.to, raw.githubusercontent.com); Password Manager का optional breach check SHA-1 hash के सिर्फ़ पहले 5 अक्षर api.pwnedpasswords.com को भेजता है। Digital Khata online services (Firebase, EmailJS) इस्तेमाल करता है; Privacy Policy देखें। Privacy Shield and Password Manager do not send your browsing history or passwords to the developer. They make a few network requests: Shield downloads filter lists (easylist.to, raw.githubusercontent.com); the Password Manager's optional breach check sends only the first 5 characters of a SHA-1 hash to api.pwnedpasswords.com. Digital Khata uses online services (Firebase, EmailJS); see the Privacy Policy.
Passwords कहाँ store होते हैं?Where are passwords stored?
Password Manager आपका vault आपके device पर रखता है; app इसे किसी server पर upload नहीं करता। Extension की storage encryption का विवरण: TBD by developer। Android app (देखे गए source के अनुसार, version TBD by developer): AES-256-GCM, master password से PBKDF2-HMAC-SHA256 (600,000 iterations) द्वारा बनी key। The Password Manager keeps your vault on your device; the app does not upload it to any server. Extension storage encryption details: TBD by developer. Android app (per the source reviewed, version TBD by developer): AES-256-GCM, key derived from your master password with PBKDF2-HMAC-SHA256 (600,000 iterations).
क्या ये Chrome पर भी काम करता है?Does this work on Chrome too?
हाँ। Extension GitHub Releases से manually install किया जा सकता है (Load Unpacked / drag-and-drop)। Store links: TBD by developer। Yes. It can be manually installed on Chrome via GitHub Releases (Load Unpacked). Store links: TBD by developer.
