# Contributing to BABASITARAM PRO

Last updated: 25 October 2026

The source code of BABASITARAM PRO is kept in a **private repository**. This public repository holds the website, documentation and release downloads.

## Report a bug or suggest an improvement
- Use the **Issues** tab of this repository, or email [babasitarampro@gmail.com](mailto:babasitarampro@gmail.com).
- Please include the product (Android app, Password Manager, Privacy Shield or Digital Khata), its version (TBD by developer: shown in the app/extension), and the steps to reproduce.
- **Never post passwords, vault files, backups or screenshots that show secrets.**

## Security problems
Please do not post vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).
